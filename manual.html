한글놀이 사용법
← 앱으로 가기
한글놀이는 초성·중성·종성을 하나씩 골라 글자를 합쳐 만들며 읽기(해독)를 연습하는 도구예요. 아이가 배운 음소만 켜 두면, 놀이·게임·자료가 모두 그 범위 안에서만 만들어집니다. 소리 읽어주기(TTS)는 넣지 않고, 자모가 모여 글자가 되는 과정을 눈으로 보며 익힙니다.
① 진도 설정→ ② 놀이→ ③ 게임 / 자료 만들기→ ④ 가정과제 링크

1 진도 설정 — 아이·음소 정하기

가장 먼저 하는 단계예요. 프로필을 고르고, 오늘 배운 초성·중성·종성만 켜 둡니다.

  • 👦 아동 프로필 — 아이마다 프로필을 나눠 진도를 따로 관리해요. ＋ 추가 ✏️ 이름변경 🗑 삭제. 실명 대신 별칭을 권장해요.
  • 진도는 이 기기에만 저장돼요. 기기를 옮기거나 백업하려면 📤 내보내기로 JSON 파일을 저장하고, 새 기기에서 📥 가져오기 하세요.
  • 초성·중성·종성 타일을 눌러 배운 음소만 켜요(연두색+✓). 그룹마다 모두 해제 버튼이 있어요.
  • 종성(받침)은 ∅ 받침없음이 항상 켜져 있고, 받침을 배우면 하나씩 켜 주면 돼요.
  • 맨 위 지금 만들 수 있는 글자에서 현재 조합되는 글자 예시를 확인해요. 변경은 자동 저장됩니다.

2 놀이 — 초성·중성·종성 합치기

놀이 화면에서 자모를 하나씩 눌러 글자를 만들고, 아이와 소리 내어 읽어 봅니다.

  • 아래 세 구역 초성 중성 종성 에서 하나씩 누르면 위에 글자가 합쳐져요. (누르는 순서는 자유)
  • 같은 자리를 다시 누르면 교체, 한 번 더 누르면 해제돼요.
  • 두·세 글자 단어는 다음 글자 ＋로 이어 만들어요. (앞 글자가 잠기고 새 글자 시작 · 최대 3음절)
  • ⬅️ 지우기 마지막 자모부터 지우기 · 🧹 처음부터 전체 지우기.
  • 🎲 랜덤 글자 — 1음절 2음절 3음절 을 누르면 켠 음소로 무작위 글자를 만들어 줘요.
  • ⭐ 담기로 더 연습할 글자를 담은 단어에 모으고, ✍️ 글씨연습장으로 바로 쓰기 연습지를 만들 수 있어요.

3 게임 — 타자·터치로 읽기 연습

진도에서 켠 음소로 만든 글자가 소재가 돼요. 두 가지 게임이 있어요.

  • 🧱 벽돌깨기 — 벽돌에 적힌 글자를 타자로 치면 공이 날아가 깨져요. 시간제한이 없어 천천히 읽고 쳐도 돼요.
  • 💻 글자잡기 — 위에서 떨어지는 글자를 바닥에 닿기 전에 없애요. 생명은 하트 ❤️로 표시돼요.
  • 글자잡기 속도는 1단계·느림 2단계·보통 3단계·빠름 중에 고를 수 있어요. (기본 1단계)
  • PC에서는 타자로 치고, 휴대폰·태블릿에서는 떨어지는 글자를 정확히 읽고 손가락으로 톡 터치하면 잡혀요.
  • 글자 수(한 글자 두 글자 세 글자)로 난이도를 정하고, ⏸️ 일시정지 · 🔄 다시 · 🔊 소리 켜고 끄기가 가능해요.

4 자료 만들기 — 학습지 자동 생성

켠 음소 범위로 단어·문장 목록을 자동으로 만들어 인쇄하거나 복사할 수 있어요.

  • 유형을 골라요 — 의미 단어 / 무의미 단어 / 문장.
  • 음절 수(1·2·3)와 받침(없음만/있는것만/섞기), 개수를 정하고 ✨ 생성을 눌러요.
  • 📋 복사 다른 곳에 붙여넣기 · 🖨️ 인쇄 학습지로 바로 출력.
  • 진도에서 켠 음소만 사용돼요. 목록이 부족하면 음소를 더 켜 보세요.

ℹ️ “무의미 단어”는요

실제 사전에 없는 소리 연습용 글자예요. 고유명사·활용형은 사전에 없어도 실제 단어일 수 있으니 선생님이 한 번 확인해 주세요.

5 글씨 연습장까지 이어 만들기

만든 단어를 그대로 글씨 쓰기 연습장으로 넘길 수 있어요.

  • 놀이에서 담은 단어는 ✍️ 글씨연습장, 자료 만들기에서는 ✍️ 글씨연습장 만들기 버튼을 눌러요.
  • 그 단어들로 A4 쓰기 연습장이 새 창에서 자동으로 만들어져요. ✍️

6 가정과제 링크 — 집에서 같은 범위로 복습

치료실에서 정한 진도 그대로, 집에서 복습할 수 있는 링크를 보호자에게 보내요.

  • 진도 설정 화면의 🏠 가정과제 링크를 누르면 링크가 만들어져요. 복사해서 보호자에게 전달하세요.
  • 보호자·아이는 로그인 없이 링크만 열면 돼요. 열면 진도가 잠겨 선생님이 정한 음소 범위로만 놀이·글씨연습을 해요.
  • 링크에 아이 이름은 들어가지 않아요. 화면에는 “🏠 오늘의 연습” 배지만 보여요.

💡 알아두면 좋은 점

● 지도 순서를 강제하지 않아요 — 아이마다 배운 음소가 다르니, 선생님이 켠 음소만 조합에 쓰입니다.
● 소리 읽어주기(TTS)는 없어요 — 자모가 모여 글자가 되는 과정을 눈으로 보며 블렌딩 감각을 익혀요.
● 자동 저장 — 프로필·진도·담은 단어는 이 기기에 저장돼요. 데이터가 지워질 수 있으니 가끔 📤 내보내기로 백업하세요.
● ㅇ은 초성에 포함돼 있어요(아·어·오…는 초성 ㅇ + 모음).
